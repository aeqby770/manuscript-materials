# LineaLinkR manuscript materials

This directory contains the files prepared for manuscript submission.

- `manuscript/`: main text, supplementary material, title page, cover letter, and references.
- `figures/main/`: Figure 1-8 and the graphical abstract in PNG and PDF formats.
- `figures/supplementary/`: Supplementary Figures S1-S18 in manuscript order, in PNG and PDF formats.
- `source/`: LineaLinkR 0.6.4 source package, including package tests.
- `analysis_scripts/`: analysis and benchmark scripts.
- `data_sources/`: dataset accessions, source publications, and provenance records.
- `results/`: tabular analysis results.

Raw expression matrices and other large serialized inputs are not included. Figure-generation and manuscript-building scripts are not included.
